⚠️ Firebase Permission Denied (Missing Rules)

Google Firebase defaults to locked mode for security. To let anyone save and read poems, update your rules in Firebase Console:

  1. Go to Firebase Console → Firestore Database → Rules
  2. Paste these 7 lines into the rules editor: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  3. Click the blue Publish button!
